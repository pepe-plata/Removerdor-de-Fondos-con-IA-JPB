❓ Ayuda — Removedor de Fondos con IA JPB

Instalar como app

  1. Abre esta página en Chrome para Android.
  2. Pulsa el menú ⋮ (esquina superior derecha).
  3. Selecciona "Añadir a pantalla de inicio" o "Instalar app".
  4. Confirma el nombre y pulsa Añadir.

Compartir desde otras apps

Una vez instalada, puedes enviar imágenes desde la Galería, WhatsApp, etc. usando el botón Compartir y eligiendo Removedor JPB.

Gestos táctiles

  • 1 dedo: pan (mover la imagen).
  • 2 dedos: pinch-zoom + pan.
  • Con editor de máscara: 1 dedo dibuja; 2 dedos siguen haciendo zoom/pan.

Instalar como app

  1. Abre esta página en Chrome o Edge.
  2. Pulsa el icono ⊕ Instalar en la barra de direcciones.

Abrir con la app

Con la app instalada, puedes hacer clic derecho en una imagen y elegir Abrir con → Removedor JPB desde el explorador de Windows.

Uso básico

  1. Pulsa Abrir o arrastra una imagen.
  2. También puedes pegar con Ctrl+V.
  3. Elige modelo y pulsa Remover Fondo.

Atajos de teclado (Windows)

  • Ctrl + O: Abrir imagen
  • Ctrl + S: Guardar
  • Ctrl + C: Copiar al portapapeles
  • Ctrl + Z: Deshacer (edición de máscara)
  • Ctrl + Y: Rehacer (edición de máscara)
  • + / -: Zoom in / out
  • 0: Ajustar a ventana
  • 1: Zoom 100%
  • [ / ]: Reducir / aumentar pincel
  • Ctrl + V: Pegar imagen
  • Barra espaciadora + arrastrar: pan

Ratón

  • Rueda: zoom hacia el cursor
  • Shift + rueda: scroll horizontal
  • Alt + rueda: scroll vertical
  • Botón medio / derecho: pan

¿Cómo funciona?

Todo se ejecuta localmente en tu dispositivo (WebAssembly o WebGPU). Ninguna imagen se sube a ningún servidor.

Modelos disponibles

  • U²-Netp (4.7 MB): rápido.
  • Silueta (44 MB): buen balance.
  • U²-Net (170 MB): alta calidad.
  • U²-Net Human (176 MB): personas.
  • ISNet General (179 MB): bordes finos.

Desenfoque de fondo (bokeh)

Si activas el relleno o el desenfoque de fondo, la app procesa el fondo por separado. Puedes combinar relleno + desenfoque para conseguir efectos de retrato profesionales.

Wake Lock

Mientras la IA procesa, la pantalla no se apagará automáticamente (si el dispositivo lo permite).
